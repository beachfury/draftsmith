# DraftSmith Maven repository

This branch is a Maven-layout repository for [DraftSmith](https://github.com/beachfury/draftsmith)
release artifacts — one version per Minecraft target (26.1.2, 26.2, 26.3 and 1.21.1). It exists so
host mods (like [FabricPlots](https://github.com/beachfury/fabricplots), which bundles DraftSmith
Jar-in-Jar) and other consumers can resolve the editor as an ordinary dependency instead of
building it locally.

## Using it

```gradle
repositories {
    maven {
        url = "https://raw.githubusercontent.com/beachfury/draftsmith/maven/"
        content { includeGroup "com.draftsmith" }
    }
}

dependencies {
    // Pick the version matching your Minecraft target:
    implementation "com.draftsmith:draftsmith:1.0.1+26.3"      // 26.x branches (unobfuscated)
    // modImplementation "com.draftsmith:draftsmith:1.0.1+1.21.1" // 1.21.1 (intermediary-remapped)
}
```

Each version ships the mod jar, sources jar, POM and Gradle module metadata, with
sha1/md5/sha256/sha512 checksums. The `+1.21.1` artifacts are remapped to intermediary (built with
`fabric-loom-remap`); the `+26.x` artifacts are unobfuscated.

The API surface for host mods is `com.draftsmith.api.EditAccess` /
`DraftSmithApi.setAccess(...)` — see the main branch README's developer section.

## Publishing (maintainers)

This branch is regenerated by `tools/publish-maven.ps1` on the development branches: it runs
`publishToMavenLocal` in every branch worktree, mirrors the released versions here with fresh
checksums and `maven-metadata.xml`, and commits. Don't edit artifacts by hand.
